## 판정 요약

- 조회 범위: 설치된 Python 패키지 전부(간접 의존 포함, 직전 브리프보다 넓음), 주요 상류 저장소의 보안 권고, CISA 「알려진 악용 취약점」 목록, 저장소 보안 설정.
- **알려진 취약점 1건**: 간접 의존 하나(TLS 인증서 묶음)에 공개 권고가 있다. 등급은 높지만, 악용하려면 유출된 인증 기관 키와 통신 경로 위 위치가 함께 필요하다. 영향은 HTTP 경량 수집 경로의 응답 무결성이다.
- 이번 점검은 기록만 한다. 수정(하한 추가와 환경 갱신, 회귀 검사)은 사용자 승인으로 별도 과제에서 한다.
- 상시 관리 2건: ① 브라우저 런타임 최신 유지(지금 안정판보다 뒤처짐) ② 런타임에 내장된 압축 해제 구성요소의 판 확인(미확인).
- 직전 브리프(2026-10-31)의 「저장소 보안 기능 점검」 권고는 닫혔다(켜짐 확인).
- 다음 수집: 7일 뒤 또는 의존성 변경 시.

상세·근거·설정 실측값은 공개 저장소에 두지 않는다(위 비공개 경로 참조).
