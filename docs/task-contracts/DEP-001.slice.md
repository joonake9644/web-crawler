# 조각 DEP-001: scrapling 0.5 호환을 판정해 상한을 옮기거나 근거를 남기고, 런타임을 허용 범위 안 최신으로 올리며 certifi 하한을 건다

- 계획 과제: DEP-001
- 허용 경로: .gitignore, requirements.txt, scripts/test_requirements.py, docs/reference/scrapling-0.5-compat-2026-11.md, docs/task-contracts/DEP-001.slice.md, .harness/state.json, docs/session-handoff.md

## 합격 기준
1. scrapling 0.5 의 바뀐 점을 원문(변경 기록·릴리스 노트)으로 확인하고, 0.5.1 을 저장소 밖 임시 환경(3.14·3.11)에 설치해 `pytest -q -k "not e2e"` 와 이 저장소가 쓰는 fetcher 경로(import·생성 경로)를 돌린 결과가 `docs/reference/scrapling-0.5-compat-2026-11.md` 에 원문 출처·명령·결과와 함께 있다.
2. 결과가 호환이면 `requirements.txt` scrapling 상한을 옮기고(상한 검사를 먼저 고쳐 RED 확인), 비호환이거나 확인이 부족하면 `<0.5` 를 유지하고 그 근거를 `requirements.txt` 주석과 위 평가 문서에 남긴다.
3. `requirements.txt` 에 `certifi>=2026.10.19` 하한이 있고, `scripts/test_requirements.py` 하한 검사를 먼저 써서 RED 를 확인한 뒤 GREEN 이다. OSV 재조회에서 설치된 certifi 권고 0건이다.
4. 로컬 `.venv` 가 허용 범위 안 최신(playwright·patchright 1.64.x, curl_cffi 0.17.x, certifi 하한 이상)이고, playwright·patchright 제약식은 바이트 동일하다(ADR-002, 기존 검사 통과).
5. 실행 계약 6종과 3.11 환경 `pytest -q -k "not e2e"` 가 모두 exit 0 이다.

## 불변 제약
- playwright·patchright 상한 `<1.65` 는 바꾸지 않는다(PY311-001 상시 조건). 두 줄 제약식은 바이트 동일을 유지한다(ADR-002).
- scrapling 0.5 의 새 기능은 도입하지 않는다(호환 확인까지만). `scripts/` 제품 코드는 고치지 않는다 — 고쳐야 호환되면 상한을 유지하고 갭으로 넘긴다.
- 시험 환경(3.14·3.11)은 저장소 밖(`~/.cache/web-crawler-dep001/`)에 만든다. 저장소에 lockfile·새 venv 를 두지 않는다.
- `active_work`(PY311-001)·승인 고정 sha256·ADR 기준점은 바꾸지 않는다.
- 하네스 핵심 파일(`.plan/`, `.claude/`, `CLAUDE.md`, `AGENTS.md`, 스킬·훅)은 고치지 않는다(applygo36 ADR-019 하네스 동결, 전역 관문 HCG).
