## 사다리 3단 대체 설계(REV-7 이 요구한 선결 설계)
- 0.5 는 일반 Playwright 백엔드(`DynamicFetcher`)를 없앴고 남은 브라우저 백엔드는 patchright 기반 `StealthyFetcher` 뿐이다. `StealthyFetcher` 는 이음매 아래 사다리 B(통지 게이트 대상)이므로 3단 대체로 쓰지 않는다.
- `scripts/utils.py` `plain_dynamic(url, **kw)` 를 **playwright 직접 호출**(`playwright.sync_api`, 위장 없는 Chromium — 이미 `requirements.txt` 에 직접 선언됨)로 다시 만든다. 이름·위치·사다리 등급(A 3단 `js_render`)은 그대로다.
- 반환형은 지금과 같은 scrapling 응답(`scrapling.engines.toolbelt.custom.Response`: `.status`·`.css()`·`.xpath()` 등)이다. 렌더된 `page.content()`·최종 URL·상태·헤더·쿠키로 만든다.
- 지원 인자는 저장소 안 실제 호출이 쓰는 것만: `network_idle`, `page_action`, `headless`(기본 True), `timeout`, `wait_selector`. `google_search` 는 조작된 Referer 를 붙이지 않는 것이 기본 동작이므로 받아서 무시하지 않고, `True` 가 오면 오류로 거부한다(출처를 지어내지 않는다는 3단 원칙). 그 밖의 인자는 조용히 버리지 않고 `TypeError` 로 거부한다.
- 프로필·문서의 `DynamicFetcher`·`DynamicSession` 은 `plain_dynamic`(3단)으로 바꾼다. 옛 프로필의 옛 이름은 `scripts/profile_policy.py` 매핑으로 계속 3단으로 읽고, `plaindynamic` 키를 매핑에 더한다.

## 합격 기준
1. `requirements.txt` scrapling 제약이 `>=0.5.1,<0.6` 이고, `test_scrapling_has_upper_bound` 를 먼저 `<0.6` 기준으로 고쳐 지금 파일에서 RED 를 확인한 뒤 GREEN 이다.
2. `plain_dynamic` 이 위 설계대로 playwright 직접 호출로 동작한다. 단위 시험(가짜 playwright 로 인자 전달·`google_search=True` 거부·모르는 인자 거부·반환형)을 먼저 RED 로 쓰고 GREEN 이다. 로컬 HTML 파일(`file://`)을 실제 Chromium 으로 렌더해 `.css()` 로 값을 읽는 시험 1건이 통과한다.
3. `scripts/preflight.py --core-only --no-network` 가 scrapling 0.5.x 환경에서 CORE FAIL 0 이다(`DynamicFetcher` 대신 playwright 일반 Chromium 실행 확인).
4. 코드·스킬 정본·참조 문서·프로필에서 `DynamicFetcher`·`DynamicSession` 을 쓰라는 지시가 0건이다(옛 이름 매핑과 「옛 이름」이라고 밝힌 설명 제외). `test_doc_contracts.py` 의 문서 import 검사가 0.5.x 환경에서 통과한다. `.codex/` 미러는 `sync_codex_mirror.py` 로만 다시 만든다.
5. 실행 계약 6종과 3.11 환경(scrapling 0.5.x) `pytest -q -k "not e2e"` 가 모두 exit 0 이고, 평가 문서에 판 올림 결과(판·시험 수·남은 차이)를 더한다.

## 불변 제약
- 사다리 3단은 이음매 위에 남는다. 3단 경로에서 patchright·`StealthyFetcher`·위장 헤더·조작된 Referer 를 쓰지 않는다(`AGENTS.md` 「안전 — 하드룰」 첫 줄).
- playwright·patchright 제약식 바이트 동일(ADR-002)과 상한 `<1.65` 는 그대로다.
- scrapling 0.5 새 기능(`RemoteSession`·`record_requests`·`pierce_shadow` 등)은 도입하지 않는다.
- `.claude/skills/web-crawler/**` 수정은 전역 관문(HCG) 대상이다. 고치기 전에 관문 보고(현행·대조·판정)와 승인 범위 목록을 만들고 사용자의 「하네스 변경 승인 HCG-<번호>」 입력을 받는다. 범위는 이름 바꾸기와 3단 설명 갱신뿐이며 안전 규칙·통지 게이트 문장은 바꾸지 않는다.
- 하네스 엔진·`.plan/`·훅·`CLAUDE.md`·`AGENTS.md` 는 고치지 않는다(applygo36 ADR-019 하네스 동결). `active_work`(PY311-001)·승인 고정 sha256·ADR 기준점은 바꾸지 않는다.
- 3.11 시험 환경은 저장소 밖(`~/.cache/web-crawler-dep002/`)에 만든다.
